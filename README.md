# AI Student Impact Analysis

## Project Overview
Analisis data untuk memahami hubungan penggunaan Generative AI dengan performa akademik, retensi pengetahuan, dan risiko burnout mahasiswa.
## Objectives
- Memahami pola penggunaan AI generatif pada mahasiswa.
- Menganalisis hubungan penggunaan AI dengan performa akademik.
- Menganalisis hubungan ketergantungan AI dengan retensi pengetahuan.
- Mengidentifikasi pola risiko burnout mahasiswa.
- Mengelompokkan mahasiswa berdasarkan intensitas penggunaan AI.
## Tools
- R
- R Markdown
## Analysis
Project ini mencakup:
- Data understanding & profiling
- Data cleaning & validation
- Exploratory Data Analysis (EDA)
- Statistical analysis
- Student segmentation
- Data-driven insights
## Key Findings
- Penggunaan AI memiliki korelasi negatif yang sangat lemah dengan Post-Semester GPA.
- Penggunaan AI memiliki korelasi negatif dengan Skill Retention.
- Ketergantungan AI memiliki korelasi negatif dengan Skill Retention.
- Heavy User memiliki proporsi High Burnout paling tinggi.
- Perbedaan GPA antar segmen penggunaan AI relatif kecil.

## Conclusion
Hasil analisis menunjukkan bahwa penggunaan AI lebih terlihat berkaitan dengan retensi pengetahuan dan risiko burnout dibandingkan dengan perbedaan performa akademik.
